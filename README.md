# PHP Unit Testing

A collection of unit testing exercises developed while learning automated testing with PHP and PHPUnit.

The project contains validators and test cases for different types of input, including:

- CPF and CEP
- Credit card numbers
- Email addresses
- Dates
- Passwords and usernames
- Phone numbers
- URLs
- Promotional codes

## Technologies

- PHP
- PHPUnit
- Composer

## Project Structure

- `src/` — validation classes
- `tests/` — PHPUnit test cases
